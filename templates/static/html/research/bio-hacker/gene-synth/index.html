Tool 01 — Restriction digest & gel

Paste a sequence, choose enzymes, read the gel

Sequence612 bp · 49.5 % GC
Enzymes3 selected

Linear DNA, complete digest, 37 °C for 60 min. One site per fragment boundary; a circular plasmid would need one more cut to open.

    GC content25 bp window

    A gel is a measurement with a bad memory: fragments under about 100 bp run off the end, and two fragments of similar size stack into one band. The simulator draws them anyway, faintly, so you can see where the gel would lie to you.
