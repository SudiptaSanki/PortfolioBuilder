# 3D Computational & Experimental Research Campus

A procedural 6-station 3D open-world research portfolio built with Three.js, GSAP ScrollTrigger, Lenis, and procedural Web Audio — traversing an atrium, quantum cryo-optics bench, wet lab, supercomputing hall, sky-dome observatory, and dusk archive terrace.

- **Category:** `research` (`academic-clinical-research`)
- **Role:** Researcher (`researcher`)
- **Stack:** Vanilla HTML / CSS / ES Modules + Three.js + GSAP + Lenis (zero-build importmap + optional Vite)
- **Attribution:** PortfolioBuilder Core (`https://github.com/SudiptaSanki/PortfolioBuilder`)
