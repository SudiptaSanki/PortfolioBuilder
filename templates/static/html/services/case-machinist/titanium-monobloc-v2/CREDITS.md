# CREDITS — Titanium Monobloc (Feldmann Case Works)

## Persona

**Oskar Feldmann** and **Feldmann Case Works** are a fictional persona and
practice, created for this portfolio template and disclosed as fictional in the
footer of every page. No real person's name, face or work is used. The one named
client, Jonas Brandl of Atelier Brandl, is fictional as well and is described on
the site as named "with written consent" — the consent is part of the fiction;
the practice it illustrates (clients named only with consent) is real practice.
The machining figures (operation minutes, capability floors of ±0.005 mm /
±0.008 mm, scrap allowances, rates) are the practice's stated values at
established-practice level, printed in Tables T1, O1, F1, M1, Q1, P1 and E1,
and the Case Run Planner parses those same tables — Case File 02's rerun figure
of CHF 8,809.60 is exactly what the planner computes for Class S, 18 cases,
brushed finish.

## Sound ruling

**NONE.** No audio is recorded, synthesised or played anywhere on this site,
and the script creates no AudioContext. A machine shop portfolio does not
teach through sound; the ruling is printed in every page footer.
