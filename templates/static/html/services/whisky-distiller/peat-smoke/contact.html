Before you write

  • Tastings are 18+ only — seats cannot be booked for anyone younger, and ID is asked where there is doubt.
  • Getting home: the still room is a mile from Campbeltown's bus stop. Plan the journey home before the first pour, not after the last.
  • Verifications: photographs of the bottle — capsule, fill level, label front and back — speed the answer considerably. Never post a bottle anywhere before the verdict; most checks are done from photographs and records.
  • Trade: say the size of the list and the size of the budget in the first note. Both are treated as ordinary facts, not tests.

What happens next

A reply from Hamish, not a system — with dates if you asked for dates, figures if you asked for figures, and a plain no with a reason if the answer is no. Nothing you write here is added to a mailing list, because there isn't one.
