Devlog · pipeline

How a cart gets made here

No engine churn. One small toolchain, learnt properly, and a hard limit on what a screen is allowed to show.

  1. 01

    The one screen

    Every room has to read as a single 320×180 image before it is fun. I draw it in Aseprite, tile-first, with the walkable path a different colour.

  2. 02

    Tiles, then sprites

    Tilesets are 16×16, four variants per material. Sprites are 32×32 for heroes and 24×24 for enemies — small enough that a mistake is visible.

  3. 03

    Palette lock

    Sixteen colours, two of them reserved for UI. If a scene needs a seventeenth, the scene is wrong, not the palette.

  4. 04

    Godot, then export

    Logic in Godot 4, no plugins. Builds for Linux and web; the console port is handled by a porting house in Kochi.
