## Artwork — all original, drawn for this template
Every image on this site is an original flat-vector SVG drawn in code for
this template, in a miniature-inspired style. Nothing is copied from any
manuscript, miniature painting, artwork or game; no photographs are used.

- `assets/plate-archer.svg` — "The Archer at Dawn", key art plate (index hero)
- `assets/plate-turnaround.svg` — "The Archer, Three Ways", turnaround plate (Case File 01)
- `assets/plate-kingdom.svg` — "The River Kingdom, Morning", environment plate (Case File 02)
- `assets/plate-refused.svg` — "The Disc That Came Back", two-panel refused/replaced plate (Case File 03)
- `assets/plate-hermitage.svg` — "The Hermitage", environment plate (about)
- `assets/border-h.svg`, `assets/border-v.svg`, `assets/border-corner.svg` —
  the F16 ornamental folio border: an original floral/geometric margin drawn
  for this template (diamond, leaf-sprig and petal-fan motifs), used
  structurally on all four pages.

The persona (Kavya Raghunathan), studios, game titles and clients are
fictional and are disclosed as such in every page footer.
