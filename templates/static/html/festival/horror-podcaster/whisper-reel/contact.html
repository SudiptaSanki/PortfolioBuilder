I read every one. I reply only if I want to record it, which can take a month. Nothing here is published without a second conversation.

No attachments needed. If I want the recording, I will ask for it.

What happens to it

  1. I read it, usually on a Sunday night.
  2. If it fits, a phone call — twenty minutes, no recording.
  3. If we record, you hear the edit before it is published.
  4. You can withdraw it at any point, including after release.
