## Sound

The reference tones on the syllabus page are pure sine tones generated
in the browser with Web Audio at the moment a visitor taps a button
(136 / 204 / 272 Hz, peak gain 0.12, self-stopping at 1.8 s). No audio
files are used or shipped.
