## Sound ruling

One audio element exists by design: the **count-in practice tool**
(index page). A count-in is teaching material — the profession's own
working sound — so it passes the need-test under the program's strict
pattern: it starts only on an explicit Play tap, it is a synthesised
clave at a printed tempo (92 / 112 / 120 BPM, from the printed tempo
table) with the count shown on screen, fixed master gain 0.12, a Stop
control, and it stops itself after sixteen counts. **No music** is
played, sampled or implied anywhere: the songs in the case files are
invented, and real songs' rights belong to their productions — the
site's own honesty page says so. Everything else is silent.

## Design notes

Frame **F3 (kinetic type)** with its CSS spec: wide container
(~1240px), type-led layout — no photo hero, no card grids; formations
and counts set as type tables and floor diagrams; flat festival
colour on a dark stage floor (magenta/marigold), "neon" achieved
with flat colour only — zero gradients, zero glow/text-shadow haze,
zero backdrop-filter; motion vocabulary is stepped/keyframed type
only (the count lands on beats; the hook lines land after it), with a
static poster state under prefers-reduced-motion; no scroll-reveal,
no hover-lift, no shadowed cards. Type pairing: Anton (poster
display) + Archivo (text and tabular data) — IBM Plex Mono
deliberately not used. Page transition: a hard stepped cut via
cross-document view transitions, disabled under reduced motion.
The stub's garland/firefly/mandala decoration, gradient-glass cards
and GSAP scroll choreography were removed, not rebuilt; the vendor
GSAP files remain in the folder, unused, per the catalog layout.
