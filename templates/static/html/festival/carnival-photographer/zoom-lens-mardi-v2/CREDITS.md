## Sound

NONE. Ruling: carnival sound belongs to the street; the site ships silent
and the ruling is printed in the footer. The stub's vendor scripts (GSAP)
are left in the folder unreferenced; the rebuild uses vanilla JS + CSS.

## Dry-brush edge

One variant-C brush ribbon (flat gold fill, hand-drawn torn path) under the
Parade Deck on the index page only — genre-fitted (festival/creative),
one per boundary, carries no text and sits under no tap target.

## Frame & CSS spec (Frame Diversity Directive)

- Frame: F6 GALLERY-FIRST — the first screen is a wall of frames with the
  proposition set small among them; one gallery (the Parade Deck) is a
  draggable deck with native swipe on touch and a static row under
  reduced motion.
- CSS spec: wide container (1280px); varied-height gallery grids
  (3/2, 4/3, 3/4, 2/3, 16/9 mixed — no uniform 3-column card grid);
  borderless frames with captions BELOW the image; no shadow cards;
  no hover-lift; NO scroll-reveal — a gallery is simply there.
- Mardi Gras purple / green / gold used as flat colours only; no gradients.
