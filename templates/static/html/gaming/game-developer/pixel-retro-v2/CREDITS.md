# Credits — Vega Pixel Works (pixel-retro)

Marisol Vega / Vega Pixel Works is a fictional persona created for
this template. Titles, clients and figures in the copy are
illustrative; the practice described — palette discipline, counted
revision rounds, first-frame approval, source-file handover — is
stated at established trade level.

## Artwork (the template's own — no photography, deliberately)

All pixel artwork on this site was drawn for this template as
character-map data in `script.js` and is rendered in the browser as
SVG at true pixel scale (`shape-rendering: crispEdges`). No
photography is used anywhere on the site: for a fictional persona,
a stock photograph of "an artist at a desk" would be exactly the
mockup-dressed-as-evidence the honesty page argues against, so the
site shows its own sprites instead.

- **The lighthouse** (16 × 16, 6 colours — counted from the artwork
  by the palette counter on the home page): the practice mark, the
  Lanternfall hero sprite, and the counted sprite in the tool.
- **The keeper walk cycle** (12 × 14, 6 colours): frames 1–4 of 8
  shown; frames drawn for this template.
- **The Lanternfall cover scene** (48 × 27): flat bands, a boat,
  rocks and waves, with the lighthouse sprite itself placed in
  situ — the same artwork data, not a separate painting.
- **The Thornwick tileset strip** (four 16 × 16 tiles: grass, dirt
  path, water, fence), drawn for the commission case file.
- **The Glass Meridian compass rose** (16 × 16, 4 colours), drawn
  for the shelved case file.

## Sound

One fenced exception, stated on the page and in the footer: the
home page's "Play the sketch" button synthesises a seven-note
figure live (square wave, Web Audio), labelled as a synthesised
sketch — not a recording, and not Lanternfall's soundtrack (which
the case file credits to a named collaborator). It starts only on
an explicit tap, plays at fixed low gain (0.10), stops itself in
about 4.6 seconds, and has a stop control. No other audio exists
anywhere in this template. The stub's hover blips were removed,
not rebuilt: hover-triggered audio is a deal-breaker on this
program regardless of genre.

## Frame & dry-brush

Frame F12 (Bento Field, pixel-grid variant) as assigned under the
Frame Diversity Directive: the bento of unequal tiles on a visible
16 px grid organises every page; CSS spec — 1240 px container,
6-column tile grid (not the program's convergent 3-column card
grid), hard offset pixel shadows with 2 px ruled borders (no soft
shadow cards, no hover-lift on tiles), stepped view-transition
easing, Silkscreen/Archivo pairing (no IBM Plex Mono).
The dry-brush edge pattern was not used: this template's surface
is a pixel grid, and a torn paint edge would fight the grid's own
geometry; the divider language here is the hard tile shadow.
