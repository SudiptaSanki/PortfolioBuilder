## Sound
No audio files. Every track in the session player is an original arrangement written for this template (section maps and note patterns in script.js), synthesised live with the Web Audio API — kick, hats, clap, bass, lead and pad voices built from oscillators and filtered noise. The pages state plainly that these are demonstration renderings of the arrangements, not mastered releases. Audio starts only on an explicit Play press (or a section tap, which is also a deliberate play action), never on load, scroll or hover; the intake stub's click-anywhere bass blast and strobe flash were deleted under the owner's sound rules — flashing content is also a photosensitivity hazard and has no place in a booking tool.
