# CREDITS — Particle Field (particle-field)

Persona disclosure: Noor Haddad and Particle Field are fictional. The
productions (Cinderfall, The Longest Gale, Aurora Bank "Ignite",
Hollow Crown, Meridian, Solstice), the client and the testimonial on
this site are invented for this portfolio template. No real film,
production or person is depicted. Prices, pipeline facts and the
failure stories are written to be true to how feature-film particle
supervision is actually bid and delivered.

Sound: none. The stub's "particle synth audio" was deleted — a film
VFX supervisor is not a sound trade, so it fails the program's sound
need-test; the research digest also records that background audio
hurts portfolios. Hover-triggered audio is a deal-breaker regardless.

The Wedge Bench (index) is original code written for this template:
a canvas-2D particle wedge whose settings readout translates into
production language (sim class, final-scale particle count, cache
estimate, farm time). The still frame shown without JavaScript or
under reduced motion is an original SVG drawn for this template.
No Three.js: canvas 2D meets the need, per the stack-discipline rule.
