## The crate data

The 33 records in the set builder and the printed crate table are real,
well-known recordings (artist, title, year). Their BPM, Camelot key and
playing length are presented as the DJ's own working data so the set
builder's arithmetic — start times, totals, tempo steps — can be checked
against the printed table. The site claims no ownership of these recordings
and plays none of them.

## Sound ruling

**No set audio, by design.** A DJ's product is other people's recordings:
they cannot be licensed for this template, and synthesising imitations of
them would be dishonest. The stub's promised "needle scratch audio feedback"
(hover-triggered) was deleted — hover audio fails the owner's sound
need-test outright.

The only audio on the site is the tap-tempo **click**: a plain metronome
blip generated with the Web Audio API, which exists only after the visitor
deliberately presses "Play click", and stops on "Stop click". It is a
working tool for finding a record's BPM, labelled as such on the page.
