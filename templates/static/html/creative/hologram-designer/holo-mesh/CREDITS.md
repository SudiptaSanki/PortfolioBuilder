# Credits — Holo Mesh

## Persona & content
Iris Kwan and the Holo Mesh studio are fictional, and so are all
clients named on the site (Meridian Gallery, the Northline OEM,
Velora). The disclosure appears in the footer of every page. The
platforms, budgets, viewing-cone and tracking figures describe real
spatial-interface practice; no real person's name, face or work is
used or imitated.

## The 3D specimen (SPEC-01)
The viewer model — plinth, prism core, three interface panels,
anchor points and gesture ring — is original procedural code written
for this template, rendered with Three.js r187.

- **Three.js** (MIT License) — vendored locally in `vendor/`
  (`three.module.js`, `three.core.js`), copied from the known-good
  vendor set in the AI/ML portfolio project. No CDN is used.
- The static fallback plate is an original hand-drawn SVG in
  `index.html`.
- **Why 3D at all:** this is the one trade in the set whose product
  *is* interactive 3D interface work, and template.json's own
  promised signature interaction was a 3D wireframe specimen. The
  viewer demonstrates the deliverable (orbit, layers, live geometry
  counts) rather than decorating the page; it is off under
  reduced-motion and absent without WebGL, where the plate serves.
