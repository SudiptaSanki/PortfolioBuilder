§ 01

The membrane bench

A leaky integrate-and-fire neuron is four numbers and a threshold: how fast the membrane leaks, how strongly current moves it, how much noise it carries, and what it does after a spike. Move them and the same cell goes from silent to regular to bursting. The raster below is sixteen cells with currents jittered by 15 %, which is what a real population looks like.

Method Forward Euler, dt = 50 µs, 400 ms per run, fixed noise seed so the same settings always produce the same trace.

Single-cell dynamics and STDP window

Vrest = −70 mV, Vreset = −72 mV, both fixed. Drive is scaled by the synaptic weight, so the same cell can be silent at 0.2 and tonic at 1.4 without touching anything else.

§ 02

Current work

Three threads, all of them eventually about the same question: how much of a perception stack can be done with events and a handful of membrane states before accuracy starts to cost more energy than it saves.

Hardware Loihi 2 (Lava), Speck, and a Prophesee GenX320 sensor on loan from the lab next door.
Sparse front end

Event-driven corner detection

A learned 5×5 event kernel that replaces the Harris detector on a 320×320 sensor. The point is not accuracy; it is that a static scene produces no events, so a camera pointed at an empty corridor uses 40 µW instead of 180 mW.

Bench: 1.4 % of pixels active per frame · 0.9 mJ per inference

Dynamics

Calibrating LIF to measured silicon

Simulated LIF neurons drift from hardware because of mismatch in the reset path and the bias current. We fit per-neuron τ and threshold from a short calibration sweep, then verify the fitted model against held-out spike trains.

Median rate error: 3.8 % across 512 neurons

Learning

STDP under a spike budget

Unsupervised STDP converges, and then the network fires more than the energy budget allows. We add a per-neuron refractory penalty during training so the learned representation is the best one that respects the event budget.

−27 % spikes at equal linear-probe accuracy

Evaluation

What to count instead of FLOPs

For an event-driven system, inference cost depends on the input, not just the model. A fair comparison reports energy per event and energy per correctly classified sample on the same data, with the sensor included.

Position paper, under review · preprint in the notebook

§ 04

From the notebook

Delft Written in the lab, edited on the train.

The first thing a new student learns in this lab is that a spiking network is not a cheaper neural network. It is a different accounting system. A dense layer pays for every multiply whether the input is a face or a blank wall. A spiking layer pays per event, so a blank wall is nearly free and a crowd is expensive. Whether that is a good trade depends entirely on the data, which is why we measure the data before we design the chip.

The second thing they learn is that the simulator lies politely. A LIF neuron in Python with a 1 ms step will happily produce a beautiful spike train that the silicon cannot reproduce, because the reset path has a time constant and the bias currents are not identical across a thousand neurons. Calibration is not a detail added at the end; it is the difference between a result and a demo.

“Energy per inference” is not a property of a model. It is a property of a model, a sensor, a dataset and a clock.

We publish the harness with the paper. It is not charity: a result that cannot be rerun on the same sensor with the same seed is a story about a result.
