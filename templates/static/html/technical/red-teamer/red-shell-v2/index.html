§01The detection scorecard

FORM RS-2 · REV 4

Every Red Shell exercise ends with this sheet, filled in from the white cell’s log and the client’s own detection records. This is a working copy: step the attempted and detected counts for an exercise shape and watch how the practice would score it. The classes are tactic classes only — what was attempted is recorded by category, never by procedure.

The printed rule

Detection rate = actions detected ÷ actions attempted × 100 — per tactic class, and overall. An action counts as detected when the client’s own tooling or team raised a record of it inside the exercise window. The white cell adjudicates disputes, and its log is the referee’s sheet.

§03Rules of engagement, in summary

FORM RS-4 · SIGNED BEFORE ANYTHING RUNS
RULE 01

Signed before anything runs

Named authorisers on both sides, a written scope, and a defined exercise window. If the signature page is not complete, the team does not start — there are no exceptions for deadlines.

RULE 02

A white cell staffed throughout

A controller sits outside the attacking team with the client’s authoriser on one call. The white cell logs every action with a timestamp and can halt the exercise at any moment, for any reason.

RULE 03

Stop conditions are printed

Safety boundaries, live-service impact and excluded systems are written into the scope before the window opens — and a stop is a success of the rules, not a failure of the exercise. See Exercise STOPLINE.

RULE 04

Objectives are synthetic tokens

Flags are planted tokens with no value outside the exercise. No real customer record is ever the objective, and if real data is encountered by accident, the action stops and the white cell is told first.

RULE 05

Everything is logged

Every action, alert and decision is timestamped on one shared clock. That log — not anyone’s memory of the week — is what the after-action report is built from.

RULE 06

Findings belong to the client

The report is delivered to the client only. Red Shell publishes nothing about an engagement — the three files on this site appear with written permission, at class level, with identifying detail removed.
