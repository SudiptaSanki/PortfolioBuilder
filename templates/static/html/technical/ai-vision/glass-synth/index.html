01 / Perception inspector

Detections are a negotiation between a threshold and the optics.

One synthetic frame, eleven candidate boxes, a real NMS pass and a real defocus model. Nothing is pre-rendered.

Detection, suppression and depth of field

The frame is drawn procedurally into three depth bands. Aperture and focus decide how much each band is blurred; the detector proposes boxes, NMS removes duplicates above the IoU threshold, and the edge map is computed from the rendered pixels rather than drawn by hand.

03 / Method

Calibrate the optics before blaming the network.

01

Measure the lens

Focal length, distortion, rolling shutter and the real aperture curve, measured on a rig rather than read from a datasheet. Half of the depth error in a lab demo is a lens model that was never checked.

02

Build the failure set

Frames where the system was wrong, kept with the reason: smoke, specular reflection, motion blur, an instrument that looks like another instrument. That set decides what gets fixed.

03

Report uncertainty

A depth map without a confidence value cannot be used by a controller that has to decide whether to move. We predict per-pixel uncertainty and check it is calibrated, not just present.

04

Run at frame rate

The model has to fit the robot's control loop on the robot's computer. A 31 ms budget on an Orin NX is the constraint that shapes the architecture, not the other way round.
