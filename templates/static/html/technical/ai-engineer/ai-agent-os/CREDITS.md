# Credits — ai-agent-os

## Persona & content
Nadia Rahman is a fictional agent systems engineer; the fiction is
disclosed in the footer of every page. The engagements are
illustrative composites written for this template. The run trace in
§01 is a constructed example whose arithmetic is real: every cost is
computed from the token counts and the rate card printed on the page
($3.00 / $15.00 per 1M tokens, frontier class; $0.30 / $1.50, small
class — rate classes, not product endorsements). Reliability figures
in the case files are stated as measured on the client's own
evaluation or traces, never as universal claims.

## Honest replacements
template.json's theme ("Cyberpunk Desktop OS") and the stub's
signature interaction — a "RUN AGENT TEST" button that typed canned
log lines ending in "Accuracy 99.9%", beside a fake "8x H100 ONLINE"
status bar — were slop: a fake agent runner producing a fake
accuracy figure is precisely the demo-theatre this practice exists
to criticise. They were deleted, not rebuilt. In their place: the
Trace Explorer (a real run, stepped through, priced from its own
token counts, with its failure step annotated) and the cost panel.
The stub's glassmorphic OS windows, backdrop blur and neon palette
were likewise removed; the design system is the run trace /
evaluation report.

## Sound ruling
FAILS the need-test — no audio anywhere in this template. An agent
console that beeps teaches nothing; hover- or run-triggered sound
is a deal-breaker pattern regardless. The ruling is stated in every
footer.
