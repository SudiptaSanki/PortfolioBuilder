## Sound

None. No audio files, no Web Audio, no console beeps. Ruling: the
profession is read, not heard — audio failed the owner's need-test
and was not built. The ruling is printed in every page footer.

## Code

Hand-written HTML/CSS/JS for this template. No frameworks, no build
step. The hero console is a fixed command index implemented in
script.js — it performs lookups over the page's own printed content
and arithmetic over the printed token-price table (Table 1), which
the script parses from the DOM so tool and table cannot disagree.
