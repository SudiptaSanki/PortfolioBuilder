04 / Contact

Bring a failure, not a vision deck.

The most useful first message names one thing the system gets wrong today and what happens when it does. From there I can tell you in a call whether an eval, a retrieval rebuild or a smaller model is the honest next step.

Project enquiry

No newsletter, no CRM sequence. The details stay in this thread and are deleted if we do not work together. I answer on Mondays and Thursdays.

What makes a good first message

  • The failure, in one sentence
  • Roughly how often it happens
  • What a wrong answer costs
  • Which model and retrieval you run now
  • The metric you would accept as success

If you have twenty of the failures in a spreadsheet, send it. That document is worth an hour of meeting.

Not a fit

  • A demo with no production traffic yet
  • Fine-tuning as the first move
  • An AI strategy deck
  • Anything that needs a decision this week

Saying no early is kinder than saying it in week three. If it is not a fit I will point you at someone better placed, and that costs nothing.

What happens next

A 45-minute call, no slides: the failure, the data you have, and the metric that would count as fixed. If it looks like a fit, I send a two-page scope with the baseline I expect to reach and the price. If it does not, I say so on the call and suggest where else to look.
