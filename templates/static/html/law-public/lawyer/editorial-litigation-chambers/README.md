# Editorial Litigation Counsel Portfolio

An editorial one-page portfolio for an appellate and commercial litigation practice, featuring GSAP + Lenis smooth scrolling, parallax plates, a sticky right-hand index rail, interactive practice/matter tabs, and consultation inquiry modal.

- **Category:** `law-public` (`legal`)
- **Role:** Lawyer / Appellate Counsel (`lawyer`)
- **Stack:** Vanilla HTML / CSS / JS (GSAP ScrollTrigger + Lenis, zero 3D, zero external font/CDN dependencies)
- **Attribution:** PortfolioBuilder Core (`https://github.com/SudiptaSanki/PortfolioBuilder`)
