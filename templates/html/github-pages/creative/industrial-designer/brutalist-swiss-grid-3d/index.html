The artifact is the only client we never bill.

Every project starts here: one object, drawn live, with no texture and no photograph to hide behind. It is a study in refraction, a drawing tool we never shipped, and the house style guide compressed into a single mesh.

It has been re-cast 1,204 times since 2019. It has never held the same silhouette twice. Drag it. Change its state. Break it — the shader will forgive you.

Studio

FOUR PEOPLE — ONE MALFUNCTIONING DEVICE — BERLIN

We are a small studio with an unreasonable tolerance for unfinished things. We prototype in the browser at the same speed we sketch on paper, which means the thing you approve is very close to the thing that ships.

Founded in 2019 by a type designer and a graphics engineer who kept arguing about the same corner. We work with cultural institutions, hardware teams and anyone else who has run out of patience for a deck.
