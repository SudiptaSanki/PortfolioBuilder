# UI & Structural Similarity Audit Across All 712 Templates

> **Scope:** Read-only UI & architecture audit across all 712 templates (no template UIs were altered).  
> **Purpose:** Identify templates that share base HTML/CSS skeletons or overlapping 3D HUD shells/topics so future UI redesign passes can target high-impact templates systematically.

## 1. Festival Collection (200 Templates — High Visual Similarity)

- **Root Cause:** Generated by `scripts/festival/generate.js`, all **200 templates share 1 identical base CSS stylesheet** (`style.css` stripped of `:root` color tokens hashes to `c090d331` for 200/200) and rotate across 3 `layout-*` classes (`layout-0`, `layout-1`, `layout-2`) combined with reveal/scroll modifiers (`60` DOM combinations across 200 templates, 2–5 templates per combination).
- **Largest Identical DOM Clusters (examples):**
  - **5 templates (`5096fbae`):** `amber-orchard`, `ganga-reel`, `pranayama-flow`, `mridanga-beat`, `yukata-cotton`
  - **4 templates each (multiple clusters):** e.g., `polka-keys` / `agave-ember` / `sherwani-line` / `zardozi-night`; `wind-beast` / `block-bazaar` / `alpine-whey` / `lehenga-luxe`; `marigold-dawn` / `couplet-brush` / `gingerbread-manor` / `vivaha-gold`
- **Recommendation:** Keep the rich decoration SVG assets (`garland`, `float`, `footer`, `pattern`), and introduce **5–6 distinct page architectures** (e.g., Magazine Editorial Spread, Fullscreen Split Hero, Masonry Gallery Grid, Interactive Card Deck, Minimalist Typography-First) so neighboring Festival templates look structurally distinct.

## 2. Genre Lab (205 Templates — High Structural Repetition)

- **Root Cause:** Generated by `scripts/genre-lab/effects.js`, producing **57 DOM clusters containing 191 of 205 templates** where 4–6 unrelated professions share the exact same HTML skeleton + hero/work permutation.
- **Largest Clusters (6 templates each):**
  - `school-teacher-mono` (`educator`), `game-developer-dark` (`gaming`), `bookstore-dark`, `ceramic-shop-mono`, `toy-store-deep` (`retail`), +1
  - `civil-engineer-dark`, `electrical-engineer-deep` (`engineering`), `music-producer-dark` (`music`), `bakery-mono`, `perfume-store-deep` (`retail`), +1
  - `electrical-engineer-dark` (`engineering`), `bakery-deep`, `coffee-roaster-mono`, `perfume-store-dark` (`retail`), `cybersecurity-analyst-mono` (`technical`), +1
  - `mechanical-engineer-dark`, `robotics-engineer-deep` (`engineering`), `game-developer-mono` (`gaming`), `violinist-dark` (`music`), `bookstore-mono` (`retail`), +1
  - `bakery-dark`, `bicycle-shop-mono`, `coffee-roaster-deep` (`retail`), `cybersecurity-analyst-deep` +2 (`technical`)
- **Recommendation:** When generating future profession expansion packs (Stage 10), introduce category-tailored layout skins (Clinical Clinic Card Layout for `medical`, Technical Spec Table Layout for `engineering`/`transport-aviation`, Academic CV/Publications Layout for `research`/`educator`) instead of using one single layout family across all industries.

## 4. Overlapping Shells & Topics Among the 11 Newly Added Templates

All **11** new templates have distinct content and pass validation cleanly, with the following UI shell and topic overlaps flagged for future refinement:

### A. Shared UI Shells (Different 3D Worlds, Similar Overlay Controls)
1. **Six-Station Multi-Page 3D Tour Shell (`cluster 66f80266`, 2 templates):**
   - `3d-power-substation-tour` (`engineering/electrical-engineer`)
   - `3d-ai-gpu-datacenter-tour` (`technical/ml-engineer`)
   - *Observation:* Both share identical HTML/CSS/HUD chrome (`src/ui/style.css`, `dom.js`, `journey.js`), though their procedural Three.js worlds are completely distinct (132/33 kV substation vs GPU cluster halls).
2. **Vite / ES-Module Procedural 3D Scroll Shell (6 templates):**
   - `3d-flight-deck-pilot-portfolio` (`transport-aviation/commercial-pilot`)
   - `3d-workstation-hardware-lab` (`engineering/computer-engineer`)
   - `3d-hydroelectric-dam-portfolio` (`engineering/renewable-energy-engineer`)
   - `3d-mainline-rail-loco-pilot` (`transport-aviation/loco-pilot`)
   - `3d-nature-sanctuary-showcase` (`services/eco-resort-host`)
   - `3d-devops-datacenter-cathedral` (`technical/devops-engineer`)
   - *Observation:* All 6 share the same single-page `src/styles/main.css` (~28–34 KB) scroll-rail / Web Audio HUD shell on top of Three.js + GSAP + Lenis. Each features a unique 3D scene and domain soundscape, while their floating UI panels/HUD follow the same design grammar.

### B. Topic Overlap (Data-Center / AI Infrastructure — 3 Templates)
- `3d-ai-gpu-datacenter-tour` (`technical/ml-engineer`) — 6-station multi-page AI cluster tour (Stations 01–06).
- `3d-interactive-server-room` (`technical/cloud-architect`) — Interactive clickable 16-rack server room (derived from Station 03 with added rack doors & live telemetry drawer).
- `3d-devops-datacenter-cathedral` (`technical/devops-engineer`) — Single-page scroll-driven 3D AI/DevOps data-center walkthrough.
- *Review Question for Future Pass:* All three serve distinct roles (`ml-engineer`, `cloud-architect`, `devops-engineer`), or could optionally differentiate HUD typography and color schemes in a future UI polish pass.

### C. Complementary Non-Overlapping Pair (Keep As-Is)
- `electrical-engineer-editorial-journal` (2D editorial + Ohm's law calculator) vs `3d-power-substation-tour` (3D interactive 6-station tour): **completely distinct UIs**, ideal pairing under `engineering/electrical-engineer`.
